# iperf3 GUI 测试工具 UI与功能设计说明

## 1. 项目概述

开发一款基于 Rust + Tauri 的 iperf3 图形化网络测试工具。

目标：

-   替代命令行 iperf3 操作
-   提供工程化测试流程
-   支持 TCP/UDP/Ping 综合测试
-   实时显示测试状态
-   自动生成测试报告
-   保存完整测试日志

------------------------------------------------------------------------

# 2. 界面总体布局

采用三栏式桌面应用布局：

    +------------------------------------------------+
    |                  顶部工具栏                    |
    +------------------------------------------------+
    |            |                  |                |
    |  测试配置  |    测试数据显示   |  状态/日志      |
    |            |                  |                |
    +------------------------------------------------+
    |              测试报告概要                      |
    +------------------------------------------------+

------------------------------------------------------------------------

# 3. 顶部区域

## 模式选择

程序启动后选择：

    [ 服务端模式 ]     [ 客户端模式 ]

## 协议选择

分开显示：

    [ TCP测试 ]    [ UDP测试 ]

避免 TCP 与 UDP 参数混淆。

------------------------------------------------------------------------

# 4. 左侧测试配置区域

## 测试项目列表

支持：

-   Ping连通性测试
-   TCP单向带宽
-   TCP双向带宽
-   TCP多并发流
-   TCP Reverse
-   UDP带宽
-   UDP丢包率
-   UDP抖动测试
-   长时间压力测试

示例：

    ☑ Ping测试

    ☑ TCP单向带宽

    □ TCP双向带宽

    □ UDP丢包测试

------------------------------------------------------------------------

# 5. 参数配置

## 通用参数

包含：

  参数       说明
  ---------- --------------
  服务端IP   目标设备地址
  端口       iperf3端口
  测试时间   持续时间
  并发流     TCP线程数量
  输出周期   数据刷新周期

## UDP参数

包括：

-   目标带宽
-   数据包长度
-   丢包检测周期

实时显示：

# 9. 日志文件保存功能

## 功能要求

所有测试过程日志支持自动写入日志文件。

日志文件：

-   测试开始自动创建
-   测试过程中持续追加
-   测试结束自动关闭

支持：

-   完成测试保存
-   中途停止保存
-   异常退出保存

------------------------------------------------------------------------

# 10. 日志文件命名规则

默认名称格式：

    本机端-服务端-测试项目-年月日时分秒-状态.log

示例：

    192.168.1.25-192.168.1.100-TCP单向带宽-20260803102030-完成.log

测试未完成：

    192.168.1.25-192.168.1.100-TCP单向带宽-20260803102030-未完成.log

------------------------------------------------------------------------

# 12. 错误处理

## 阻塞错误

弹窗：

例如：

-   服务端无法连接
-   iperf3启动失败
-   参数错误

提示：

    错误告警

    服务端未响应

    [重试]

    [取消]

## 非阻塞错误

仅：

-   写日志
-   标记WARN
