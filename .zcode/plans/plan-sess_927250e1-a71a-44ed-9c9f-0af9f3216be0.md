## 功能改造：网卡选择 / 带宽限制 / 报文长度扩展

### 需求映射
1. **本机 IP 默认 + 多网卡弹窗选择**：服务端 IP 默认取本机 IP；多网卡时启动弹窗选择（默认列表第一个），并可在配置面板一键重选
2. **带宽限制下拉**：默认 = 当前网卡最大带宽（实测速率），可选 100Mbps / 1000Mbps / 0（不限制）；TCP 和 UDP 均生效（已确认）
3. **报文长度扩展**：现有 128/512/1200/1472 基础上增加 1KB/4KB/8KB/16KB/32KB/64KB，默认 1KB；支持自定义，自定义值保存到配置文件（TCP/UDP 均生效，已确认）

### 已实测验证的 iperf3 3.21 行为
- UDP `-b 0` = 不限制（本机实测 60 Gbps）；UDP 不传 `-b` 则默认 1 Mbps
- TCP 支持 `-b`、`-l` 参数
- 已确认 crate API：`local_ip_address::list_afinet_netifas()`（网卡名+IP，Windows 返回友好名称如"以太网"，与 WMI NetConnectionID 一致）、`mac_address::mac_address_by_name()`

### Rust 端改动
1. **`models.rs`**
   - `TestRequest` 增加 `local_ip: String`（`#[serde(default)]`，用于日志命名/头部按所选网卡显示）
   - 新增 `InterfaceInfo { ip, mac, interface_name, speed_mbps }`
   - `NetworkInfo` 增加 `speed_mbps: u64`

2. **`system.rs`（重写）**
   - `collect_interfaces()`：`list_afinet_netifas()` 取 IPv4，回环地址排最后（默认=列表第一个）
   - `mac_of()`：`mac_address_by_name()`
   - `link_speeds()`：Windows 用一条 PowerShell `Get-CimInstance Win32_NetworkAdapter` 查询（NetConnectionID→Speed，bps→Mbps，数组/单对象两种 JSON 形态都兼容）；Linux 读 `/sys/class/net/<name>/speed`
   - 新命令 `get_network_interfaces() -> Vec<InterfaceInfo>`；`get_network_info()` 返回列表第一个 + 主机名

3. **`runner.rs`**
   - 日志命名/头部用 `request.local_ip`（为空时回退 `local_ip_address::local_ip()`）
   - `command_for`：所有客户端测试（非 ping/server）统一加带宽与报文长度参数：
     - 带宽 > 0 → `-b {n}M`；带宽 = 0 时：UDP 传 `-b 0`（不限制），TCP 不传（默认不限速）
     - `-l {packet_length}` 对所有客户端测试生效
   - 新增 `command_for` 单元测试（TCP/UDP × 带宽 0/非0、报文长度、server 模式不带 -b/-l）

4. **`settings.rs`（新模块）**
   - `settings.json` 存于 Tauri `app_config_dir()`，结构 `{"customPacketLength": n}`
   - 命令：`get_custom_packet_length() -> u32`、`save_custom_packet_length(length)`（校验 1~262144）

5. **`lib.rs`**：注册 `get_network_interfaces`、`get_custom_packet_length`、`save_custom_packet_length`

### 前端改动
6. **`types.ts`**：新增 `InterfaceInfo`；`NetworkInfo` 加 `speedMbps`

7. **`App.vue`**
   - defaults：`serverIp: ''`（加载后自动填本机 IP）、`bandwidth: -1`（哨兵→加载后设为网卡速率）、`packetLength: 1024`
   - onMounted：并行拉取网卡列表/运行时信息/自定义报文长度；先应用列表第一个（默认），网卡 > 1 时弹选择框（单选列表，默认第一项；确定=用所选，取消=用第一个）；`autoServerIp` 标记下重选网卡会同步更新服务端 IP
   - 新增网卡选择弹窗 + `pick-nic` 事件处理（保存自定义长度调用后端并写日志）
   - `runNext` 传 `localIp: local.ip`

8. **`ConfigPanel.vue`**
   - 服务端 IP 行加「本机」按钮 → `pick-nic` 事件
   - 带宽限制改为 `<select>`：`{N} Mbps（当前网卡）`（默认选中）/ 100 / 1000 / 0（不限制），按网卡速率去重；TCP/UDP 均可编辑
   - 报文长度 `<select>`：128/512/1KB(默认)/1200/1472/4KB/8KB/16KB/32KB/64KB + 已保存自定义值（显示"（自定义）"）+ 「自定义…」选项；选自定义显示输入框 + 保存按钮 → 调用后端持久化
   - 新增 props：`local`、`savedCustomLength`；新事件：`pick-nic`、`save-custom-length`

9. **`Dashboard.vue`**：本机网络信息增加「网卡带宽」行
10. **`styles.css`**：补充网卡选择弹窗列表样式、IP 输入行内按钮样式
